# 魔A量化交易系统 - EXE打包使用指南

## 🚀 快速开始

### 方法一：一键打包（推荐）
```bash
cd MoA-ui
python quick_build.py
```

### 方法二：手动打包
```bash
cd MoA-ui
python build_exe.py
```

## 📋 打包流程说明

完整的打包流程包括以下步骤：

1. **环境检查** - 检查Python版本和必要文件
2. **依赖安装** - 安装PyInstaller和Flask依赖
3. **前端构建** - 构建Vue.js前端到静态文件
4. **清理构建** - 清理之前的构建文件
5. **exe打包** - 使用PyInstaller打包为exe
6. **创建启动器** - 生成启动脚本和说明文档

## 📁 输出文件

打包完成后，将在 `dist/` 目录下生成：

- `魔A量化交易系统.exe` - 主程序文件
- `启动系统.bat` - Windows启动脚本
- `便携版启动.bat` - 便携版启动脚本
- `README_打包版本.md` - 使用说明文档

## 🎯 使用方法

### 启动系统
1. 双击 `启动系统.bat`
2. 等待系统启动完成
3. 在浏览器中访问 http://localhost:3001

### 直接运行
1. 双击 `魔A量化交易系统.exe`
2. 在浏览器中访问 http://localhost:3001

## ⚙️ 配置文件说明

### config.py - 打包配置
```python
# 打包模式配置
DEBUG = False                    # 关闭调试模式
STANDALONE_MODE = True           # 启用独立模式
PACKAGE_BUILD = True             # 标记为打包构建
STATIC_FOLDER = 'static'         # 静态文件目录
```

### build_exe.spec - PyInstaller配置
- 指定主脚本：`server/app.py`
- 包含数据文件：前端静态文件、配置文件
- 隐藏导入：Flask、SQLAlchemy、abupy等模块
- 排除模块：测试工具和不必要的GUI库

## 🔧 技术特性

- ✅ **自动启动** - 一键启动脚本

## 🛠️ 故障排除

### 常见问题

1. **端口占用**
   - 关闭其他占用3001端口的程序
   - 或修改config.py中的PORT配置

2. **权限问题**
   - 以管理员身份运行
   - 检查杀毒软件拦截

3. **依赖缺失**
   - 重新运行打包脚本
   - 手动安装缺失的Python包

4. **前端构建失败**
   - 检查Node.js环境
   - 确保npm可以正常安装依赖

### 调试模式

如需调试，可以：
1. 运行 `便携版启动.bat` 启动开发模式
2. 分别启动前端和后端服务
3. 查看控制台输出定位问题

## 📊 系统要求

- **操作系统**: Windows 7/8/10/11 (64位)
- **内存**: 至少 2GB 可用内存
- **磁盘**: 至少 500MB 空间
- **网络**: 首次运行需要网络连接

## 📞 技术支持

如遇到问题：
1. 检查系统要求是否满足
2. 查看错误日志输出
3. 尝试重新打包
4. 检查防火墙和安全软件设置
